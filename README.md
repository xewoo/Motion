# Motion — браузерная версия

Эта самостоятельная копия распознаёт жесты с веб-камеры в реальном времени. Видео обрабатывается локально в браузере и не отправляется на сервер. Python-приложение в корне проекта остаётся без изменений.

## Запуск в Windows

Из корневой папки проекта запустите встроенный HTTP-сервер Python:

```powershell
py -m http.server 8000
```

Откройте [http://localhost:8000/browser/](http://localhost:8000/browser/) в актуальном Chrome или Edge и разрешите доступ к камере. Нажмите **«Включить камеру»**. Для доступа к веб-камере браузер требует HTTPS или безопасный локальный адрес `localhost`; не открывайте `index.html` двойным щелчком.

При первом запуске браузер загружает MediaPipe Tasks Vision и модели распознавания с CDN. Для этого нужно подключение к интернету. После загрузки обработка видеокадров выполняется в браузере.

## Возможности

- Распознавание двух рук, 21 ключевой точки и встроенных жестов.
- Дополнительные правила для жестов «Я тебя люблю», «Средний палец», «Захват» и Six-seven (67).
- Детекция объектов и мимики лица; слои можно включать и выключать.
- Отображение сетки лица и стабилизация результатов между кадрами.
- Сбор координат 21 точки для датасета и выгрузка примеров в CSV.

Клавиши `1–5` сохраняют пример с меткой, соответствующей той же клавише в приложении Python. Примеры остаются в памяти вкладки до её закрытия; скачайте CSV до закрытия страницы.
